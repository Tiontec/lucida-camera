# 澄影重构版 · iOS

**从现在起，澄影只做重构版（真原生），网页版（11.x 系列）停止更新。**

---

## 什么是重构版

没有任何 WebView / 桥接 / 网页代码 —— **整个 App 用 Swift 原生重写**。

- 相机、取景、变焦、对焦：AVCaptureSession / AVCaptureMultiCamSession
- 界面：UIKit（液态玻璃控件、调色盘、设置面板全部原生）
- 存储：原生文件（不依赖网页 localStorage）
- 从 11.6.0 的原生双摄系统提取而来，之后在此基础上逐步补齐功能

## 版本号说明

重构版**从 1.0.0 重新计版本**，与网页版的 11.x 无关：

| 规则 | 示例 |
|---|---|
| 加设置 | +0.0.1 |
| 加功能 | +0.1.0 |
| 大更新 | +1.0.0（满 10 进一） |

## 已发布版本

| 版本 | 主要内容 |
|---|---|
| **v1.1.0** | 新增单摄模式（后置 / 前置，不要求设备支持双摄）、双摄开关（默认关闭，不支持时自动退回单摄并提示原因）、调色盘合并到当前摄像头 |
| **v1.0.0** | 从 11.6.0 提取原生双摄系统：打开直接进相机，新增多功能按键 → 功能面板（设置 / 预设顺序 / 关于），相机打不开时弹窗说明原因，设置改原生文件存储 |

## 下载安装包

全部在 **[Releases](https://github.com/Tiontec/lucida-camera/releases)**：

- `v1.1.0` / `v1.0.0` —— 重构版（`LucidaRebuild-unsigned-*.ipa`，自签后安装）
- `v11.1.0` ~ `v11.6.0` —— **网页版历史版本（已停更，仍可下载）**

## 本机构建

```bash
brew install xcodegen && xcodegen generate
open LucidaRebuild.xcodeproj
```
